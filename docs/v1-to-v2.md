# v1 から v2 への再設計

## v1 の主題と問題点

- v1 の主題は「遷移期でこそ学習モデルが優位に立てるか」であった
- test 期間を長く（572日）確保していたが、
  遷移期での学習モデルの優位性は、サンプルを増やすと再現しなかった

## 再設計の内容

- train を約1.4倍に増やした（456日 → 640日）
- 主題を「① vs ②③ の全体比較（horizon 別）」に置き直した
- 旧 v1 の全結果は、比較用に保持している

## v2 で得られた結論

- train を増やすと Chronos と学習モデルの全体差は縮まったが、埋まりきらなかった
- より明確なのは horizon による優劣の分かれ方である
  - 短期（1–24h）は常に Chronos が最良
  - 中期（48–168h）は安定期・遷移期を問わず LightGBM が上回る
- v1 では「遷移期限定」という複雑な条件付きだった結論が、
  v2 では regime に依存しない、よりシンプルで頑健な結論になった

## 再現しなかった仮説

- 「covariate がレジーム遷移を緩和する」という仮説は、
  v1・v2 のどちらの分割設計でも再現しなかった
- むしろ covariate は、遷移期ではなく安定期でこそ効く傾向が見られた
